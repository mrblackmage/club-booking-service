# Сервис бронирования компьютерного клуба

**тема:** Сервис бронирования компьютерного клуба
**Студент:** Артём Курьянов

## Описание
Микросервисный облачный сервис для компьютерных клубов: бронирование
мест, управление сессиями, внутренние кошельки, мобильное приложение
для игроков и веб-админка для персонала.

## Структура репозитория
- `README.md` — описание проекта
- `project-notes.md` — заметки и идеи
- `api-plan.md` — план API
- `git-conflict.md` — описание разрешённого конфликта слияния
- `club-booking-service/` — исходный код .NET Web API

## Стек
.NET 8 Web API, PostgreSQL, Redis, RabbitMQ, Docker.
